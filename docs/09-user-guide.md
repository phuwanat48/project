# คู่มือการใช้งาน — Todo List

> คู่มือสำหรับผู้ใช้ทั่วไป อธิบายทีละขั้นตอน ไม่ต้องมีความรู้ด้านโปรแกรมมิ่ง

---

## 1. เริ่มใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์ (double-click ได้เลย) หรือเปิด URL ที่ทีม deploy ให้
2. จะเห็นหน้าจอหลักประกอบด้วย:
   - หัวเรื่อง **Todo List**
   - ช่องพิมพ์ (placeholder: "พิมพ์สิ่งที่ต้องทำ…") และปุ่ม **เพิ่ม**
   - รายการสิ่งที่ต้องทำ (ถ้ามี)
   - แถบสถานะด้านล่าง: **ค้าง: N**, **เสร็จแล้ว: M** และปุ่ม **ลบรายการที่เสร็จแล้ว**
3. ถ้ายังไม่มีรายการ จะแสดงข้อความ "ยังไม่มีรายการ — เริ่มพิมพ์ด้านบนได้เลย" — ไม่ใช่ข้อผิดพลาด

---

## 2. เพิ่มรายการ

1. คลิกช่องพิมพ์ด้านบน
2. พิมพ์สิ่งที่ต้องทำ เช่น `ซื้อข้าวเย็น`
3. กดปุ่ม **เพิ่ม** หรือกด **Enter** บนคีย์บอร์ด
4. รายการใหม่จะปรากฏที่ **ท้ายสุด** ของ list สถานะเริ่มต้นเป็น "ยังไม่เสร็จ" และช่องพิมพ์จะเคลียร์ให้พิมพ์รายการถัดไปได้ทันที

**ถ้าลืมพิมพ์แล้วกดเพิ่ม:** ระบบจะไม่เพิ่มรายการ ช่องพิมพ์จะสั่น (shake) พร้อมข้อความแจ้งสีแดง "กรุณาพิมพ์สิ่งที่ต้องทำ" — พิมพ์ใหม่ได้เลย

---

## 3. ติ๊กว่าเสร็จแล้ว

1. คลิก **checkbox สี่เหลี่ยม** หน้ารายการที่ทำเสร็จแล้ว
2. checkbox จะเป็นสีน้ำเงินพร้อมเครื่องหมายถูก และข้อความจะ **ขีดฆ่า + สีจางลง**
3. ตัวเลขในแถบสถานะอัปเดตทันที (ค้างลดลง, เสร็จแล้วเพิ่มขึ้น)
4. ถ้าติ๊กผิด คลิก checkbox ซ้ำเพื่อกลับเป็น "ยังไม่เสร็จ" ได้

---

## 4. แก้ไขข้อความ

มี 2 วิธีเข้าโหมดแก้ไข:
- กดปุ่ม **แก้ไข** (ไอคอน ✎) ในแถวนั้น หรือ
- **Double-click ที่ข้อความ** ของรายการ

เมื่อเข้าโหมดแก้ไข ข้อความจะกลายเป็นช่องพิมพ์พร้อมข้อความเดิม (ถูกเลือกไว้ให้พิมพ์ทับได้ทันที) แล้วเลือกได้ว่า:

| การกระทำ | ผลลัพธ์ |
|---|---|
| กด **Enter** หรือปุ่ม **บันทึก** | บันทึกข้อความใหม่ |
| กด **Esc** หรือปุ่ม **ยกเลิก** | ยกเลิก — ข้อความเดิมคงอยู่ |
| คลิกที่อื่นนอกช่องพิมพ์ | บันทึกอัตโนมัติ (ถ้าข้อความไม่ว่าง) |

**ข้อควรรู้:**
- แก้ไขได้ **ทีละ 1 รายการ** — ถ้ากดแก้ไขรายการอื่นขณะแก้อยู่ รายการเดิมจะถูกบันทึกให้อัตโนมัติก่อน
- แก้เป็นข้อความว่างไม่ได้ — ช่องจะสั่นพร้อมข้อความแจ้ง และยังอยู่ในโหมดแก้ไขต่อ
- รายการที่ติ๊กว่าเสร็จแล้วก็แก้ไขข้อความได้เช่นกัน

---

## 5. ลบรายการเดียว

1. กดปุ่ม **ลบ** (ไอคอน 🗑) ในแถวที่ต้องการ
2. รายการหายไปทันที (ไม่มีหน้าต่างยืนยัน) รายการอื่นไม่ถูกกระทบ
3. ตัวเลขนับจำนวนอัปเดตทันที

---

## 6. ลบรายการที่เสร็จแล้วทั้งหมด

ใช้เคลียร์ list เร็ว ๆ ในครั้งเดียว:

1. ติ๊กรายการที่เสร็จแล้วให้ครบก่อน (ดูหัวข้อ 3)
2. กดปุ่ม **ลบรายการที่เสร็จแล้ว** ที่แถบสถานะด้านล่าง
3. จะมี **หน้าต่างยืนยัน (modal)** ขึ้นมา เช่น "ต้องการลบรายการที่เสร็จแล้ว 3 รายการหรือไม่?"
   - กด **ยืนยัน** → รายการที่เสร็จแล้วทั้งหมดถูกลบ รายการที่ยังไม่เสร็จคงอยู่ครบ
   - กด **ยกเลิก** หรือกด **Esc** หรือคลิกพื้นที่มืดรอบ ๆ → ไม่ลบอะไรทั้งสิ้น
4. ถ้ายังไม่มีรายการที่เสร็จ ปุ่มนี้จะเป็นสีจางและกดไม่ได้ (disabled)

---

## 7. นับจำนวนรายการ

แถบสถานะด้านล่าง list แสดงตัวเลข 2 ตัว อัปเดตทันทีทุกครั้งที่เพิ่ม/ลบ/ติ๊ก:

- **ค้าง: N** — จำนวนรายการที่ยังไม่เสร็จ
- **เสร็จแล้ว: M** — จำนวนรายการที่ติ๊กว่าเสร็จแล้ว

ตัวเลขตรงกับรายการใน list เสมอ รวมถึงหลัง refresh หน้าเว็บ

---

## 8. คีย์ลัด

| คีย์ | ใช้ที่ไหน | ทำอะไร |
|---|---|---|
| **Enter** | ช่องพิมพ์หลักด้านบน | เพิ่มรายการ (เหมือนกดปุ่มเพิ่ม) |
| **Enter** | ช่องแก้ไขข้อความ | บันทึกการแก้ไข |
| **Esc** | ช่องแก้ไขข้อความ | ยกเลิก — กลับข้อความเดิม |
| **Esc** | หน้าต่างยืนยันลบที่เสร็จแล้ว | ปิดหน้าต่างโดยไม่ลบ |
| **Tab** | ทั่วทั้งหน้า | เลื่อนไปยังปุ่ม/ช่องถัดไปตามลำดับ (ใช้เว็บโดยไม่ต้องใช้เมาส์ได้) |

---

## 9. ข้อควรรู้เรื่องการบันทึกข้อมูล (localStorage)

- รายการทั้งหมด (ข้อความ + สถานะเสร็จ/ไม่เสร็จ + ลำดับ) ถูกบันทึกลง **localStorage ของเบราว์เซอร์** ทันทีทุกครั้งที่มีการเปลี่ยนแปลง
- ปิดเบราว์เซอร์แล้วเปิดใหม่ หรือ refresh หน้าเว็บ — รายการยังอยู่ครบพร้อมสถานะเดิม
- **ข้อมูลอยู่เฉพาะเบราว์เซอร์บนเครื่องนั้น:**
  - เปิดด้วยเบราว์เซอร์อื่น (เช่น เปิดด้วย Chrome แล้วเปิดด้วย Firefox) จะไม่เห็นรายการเดียวกัน
  - เปิดจากเครื่องอื่นก็ไม่เห็นเช่นกัน — แอปนี้ไม่มีระบบ sync หรือบัญชีผู้ใช้
- **ข้อมูลจะหายถ้า:**
  - ล้างข้อมูลเบราว์เซอร์ (Clear browsing data / ล้าง site data ของหน้านี้)
  - ใช้โหมดไม่ระบุตัวตน (Incognito/Private) แล้วปิดหน้าต่าง
- ถ้าเบราว์เซอร์บล็อกการบันทึก (เช่น storage เต็ม) แอปจะแจ้งว่า "บันทึกไม่สำเร็จ — ข้อมูลจะหายเมื่อปิดหน้านี้" แต่ยังใช้งานได้ตามปกติใน session นั้น
- ถ้าข้อมูลที่เก็บไว้เสียหาย แอปจะไม่พัง — จะเริ่มด้วย list ว่างและใช้งานต่อได้ตามปกติ

## 10. คำถามที่พบบ่อย (FAQ)

**ถาม: รายการหายไปหลังเปลี่ยนเบราว์เซอร์ / เปิดจากเครื่องอื่น ทำไม?**
ตอบ: ข้อมูลเก็บใน localStorage ของเบราว์เซอร์แต่ละตัวบนแต่ละเครื่องแยกจากกัน แอปนี้ไม่มีระบบ sync ข้ามอุปกรณ์ ให้ใช้เบราว์เซอร์เดิมบนเครื่องเดิมจะเห็นข้อมูลเดิม

**ถาม: ลบรายการผิดไปแล้ว จะเอาคืนได้ไหม?**
ตอบ: ไม่ได้ — การลบ (ทั้งรายการเดียวและลบที่เสร็จแล้วทั้งหมดหลังกดยืนยัน) เป็นแบบถาวร ไม่มีปุ่ม undo จึงควรตรวจสอบในหน้าต่างยืนยันก่อนกด "ยืนยัน" ทุกครั้ง

**ถาม: ทำไมปุ่ม "ลบรายการที่เสร็จแล้ว" กดไม่ได้?**
ตอบ: ปุ่มจะใช้ได้เมื่อมีรายการที่ติ๊กว่าเสร็จแล้วอย่างน้อย 1 รายการ ลองติ๊ก checkbox หน้ารายการก่อน

**ถาม: มีวิธีแสดงเฉพาะรายการที่ยังไม่เสร็จไหม (filter)?**
ตอบ: ไม่มี — แอปนี้แสดงรายการทั้งหมดเรียงตามลำดับที่เพิ่มโดยเจตนา เพื่อความเรียบง่าย

**ถาม: ต้องลงทะเบียนหรือตั้งค่าอะไรก่อนใช้ไหม?**
ตอบ: ไม่ต้อง — เปิดหน้าเว็บแล้วใช้ได้ทันที ไม่มีบัญชีผู้ใช้ ไม่มีการตั้งค่า

**ถาม: ใช้งานบนมือถือได้ไหม?**
ตอบ: ได้ — หน้าจอปรับ layout อัตโนมัติสำหรับจอเล็ก (< 768px): ปุ่มเพิ่มจะย้ายไปอยู่ใต้ช่องพิมพ์แบบเต็มความกว้าง และปุ่มแก้ไข/ลบย่อเป็นไอคอน ✎ / 🗑 ที่ขนาดกดได้สะดวก

**ถาม: พิมพ์ข้อความยาว ๆ ได้ไหม?**
ตอบ: ได้ — ข้อความยาวจะตัดบรรทัด (wrap) แสดงให้เห็นครบ ไม่ทำ layout เพี้ยน

**ถาม: ข้อมูลถูกส่งขึ้นอินเทอร์เน็ตไหม?**
ตอบ: ไม่ — แอปทำงานในเบราว์เซอร์ทั้งหมด ไม่มีการส่งข้อมูลออกนอกเครื่องใด ๆ
