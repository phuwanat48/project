## Overall Impression

งานระดับสูง ความลึกมาจากคอนทราสต์ข้อความแทนเงา details ระดับ craft หรู (tabular-nums, color-scheme, reflow shake, focus trap + คืน focus ถูกจุด) โอกาสที่ใหญ่สุด: จุดที่พังทลายที่สุด (ลบเดี่ยว) กลับไม่มีบทบาทกู้คืนเหมือนที่ระบบจัดการกับรายการอื่นทุกจุด

## What's Working

1. สัญญาณสี 3 บทบาท — ตาเดาเจตนาก่อนอ่านคำ
2. Focus management ระดับผู้เชี่ยวชาญ — modal focus ปุ่มปลอดภัยก่อน, คืน focus ถูกจุดทุก flow
3. Edge cases มีคำตอบรอบตัว — editing/blur/Esc/พิมพ์ค้าง จัดการใน pub-list event ที่เดียว

## Priority Issues

1. [P1] Focus ring กลืนสีปุ่มหลัก — `#add-btn` (พื้น/ขอบ #155ab6) + ring 3px สีเดียวกัน แลปุ่ม "ยืนยัน" แดงใน modal ผู้ใช้คีย์บอร์ดมองไม่เห็นตำแหน่ง focus บนอุปกรณ์หลักที่สุดของหน้า Fix: ring สีต่างจากด้าน/ใช้ double-ring (outline + inset ขอบขาว) ใน `:focus-visible` ของปุ่มพื้น navy/red
2. [P1] ลบรายการเดียวถาวรทันที ไม่มี undo — toggle/แก้ไขย้อนได้ แต่ลบ = หายถาวรในคลิกเดียว (แตกต่างจาก clear-completed ที่มี modal) Fix: หลังลบ feedback "ลบ 'x' แล้ว — [เลิกทำ]" พร้อม window ~5 วินาที ไม่ใช่ confirm modal
3. [P2] Feedback error ค้างชั่วกัลปาวสาน — `showFeedback` ไม่มี timeout เช่น "บันทึกไม่สำเร็จ" (quota เต็ม) ค้างตลอด session Fix: timer auto-clear success feedback 5–6 วินาที + เคลียร์ทันทีเมื่อมี action สำเร็จถัดไป
4. [P2] double-click แก้ไข (desktop) เลือนราง — accelerator ไม่มี affordance/hint ที่ให้ค้นพบ ปุ่ม "แก้ไข" มองเห็นแล้วแต่ dblclick คือเส้นทางที่ไม่มีใครรู้ Fix: hint สั้น ๆ (empty-state/title) หรือยอมรับเป็น hidden accelerator อย่างตรงไปตรงมา

## Persona Red Flags

- Sam (Accessibility): focus ring กลืนสีปุ่มเพิ่ม + ยืนยัน ทำ keyboard nav พังบนจุดสำคัญที่สุด นอกนั้นเกือบสมบูรณ์
- Riley (Stress tester): จุดเดียวที่ไม่มี recovery คือลบเดียว draft ระหว่างพิมพ์หายเมื่อ refresh (ยอมรับได้ตามข้อจำกัด localStorage)
- Alex (Power user): 3 คลิกตามสัญญาทันที Enter/Esc ครบ ขาด undo ลบและสถิติที่ค้นพบด้วยตัวเอง

## Minor Observations

- title "Todo List" ต่างภาษาจาก UI หลัก (เล็กน้อย)
- counts aria-live 2 span ให้ screen reader อ่านเป็นภาพรวมทีเดียว — ดี แนะนำตรวจบนเครื่องจริง
- empty-state ชี้นำ Jordan ชัดเจน

## Questions to Consider

- ถ้ามี window 5 วินาที "เลิกทำ" หลังลบ จะช่วยให้ประสบการณ์ไหลลื่นกว่า confirm เพิ่มหรือไม่
- ถ้าทำ undo แล้ว modal ยืนยัน clear-completed ยัง defensive พอหรือควรชั้นสองน้อยลง
- จะกำหนดข้อความแจ้งแบบ temporal หรือถาวรอย่างไรให้สอดคล้องกับ aria-live state
